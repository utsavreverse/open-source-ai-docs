# Creating API Key

After creating account in NVIDIA NIM

**Step 1 : Click on the name prefix that appears on the top right of the website**

**Step 2 : Click on `API Keys` to create an API Key**

**Step 3 : Click on `Generate API Key`**

**Step 4 : Give the name to the API key and set duration of it**

**Step 5 : Copy the API Key and store it somewhere safe**

**Note** : Please copy the API key as soon as it appears, after closing the dialog box, you won't be able to see the API key again and you will need to re-generate it.
