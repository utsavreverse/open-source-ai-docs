# Nvidia Integration

To integrate [NVIDIA NIM](../nvidia/nvidia_intro.md) with OpenCode, you need an [API key](../nvidia/creating_api.md). After copying the API key, you can integrate it by doing the following steps:

=== ":material-console: TUI"

    **Step 1 : press `Ctrl`+`p` to open list of commands**

    **Step 2 : Select `Connect provider` option and search for the NVIDIA**

    **Step 3 : Select NVIDIA, paste your API key and submit it by pressing `Enter`**

    **Step 4 : Voila ! ✨  You've successfully integrated NVIDIA NIM with OpenCode**

=== ":material-monitor: Desktop"

    **Step 1 : Click on settings icon (⚙) appearing on the left sidebar**

    **Step 2 : Select `Providers` select `Show more providers` and search for the NVIDIA**

    **Step 3 : Paste your API key and click on `Continue`**

    **Step 4 : Voila ! ✨  You've successfully integrated NVIDIA NIM with OpenCode**
