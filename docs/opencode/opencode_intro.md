# Introduction

[OpenCode](https://opencode.ai/) is an open-source AI coding agent, you can think of it as an alternative to Claude Code, it is entirely free

### How it works?
It works as an interface between your codebase and LLM agents, you link LLM agents using different providers and then it will work on your codebase.

### What makes it special?
Well it is free and open-source, duh!

Lol, jokes aside, the main benefit of OpenCode is, it supports each and every LLM provider you can think of, so you can toggle between them whenever you need (so no more concurrent Claude Code, Antigravity, Cursor toggles on tokens exemption, YEY!!)

Another benefit of OpenCode is their community, since it is open source, you'll get tons and tons of plugins, and any of your issues will be resolved quickly, it is a popular repository and you can verify it by the current number of stars that repository has
